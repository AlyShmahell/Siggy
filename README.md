## Install

Linux amd64 and macOS arm64. Installs to `~/.local`.

```bash
curl -fsSL https://raw.githubusercontent.com/AlyShmahell/Siggy/main/install.sh | bash
```

Add `~/.local/bin` to `PATH` if needed, then run `siggy`.
